Every blue player is a node. Nearby teammates and opponents send messages containing their positions, technical attributes, and pressure. A fixed-weight aggregation updates each player's tactical representation. The simulation uses these graph-informed scores to select passes. This is an educational, untrained GNN-style model—not a learned neural network.

Understand the algorithm — live GNN explainer

A Graph Neural Network (GNN) processes connected entities by sharing information between neighbors. Here, football players are graph nodes, nearby players form edges, and repeated aggregation produces graph-informed features used to rank passes.
